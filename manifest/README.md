# `manifest/` — deployment manifests

| File                                | Members            | Contains                                                                                                                                                                                                                                                                                                                            | Used by                                                                             |
| ----------------------------------- | ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `core-package.xml`                  | 23 type entries    | ApexClass, ApexComponent, ApexPage, ApexTestSuite, ApexTrigger, AuraDefinitionBundle, LightningComponentBundle, StaticResource, CustomObject, CustomMetadata, CustomApplication, CustomPermission, PermissionSet, Profile, SharingRules, SharingSet, Role, Group, Network, DigitalExperienceBundle, CustomSite, Settings, CustomTab | `deploy-library.ps1` (the release package)                                          |
| `agentforce-package.xml`            | 3 type entries     | `GenAiFunction`, `GenAiPlugin`, `AiAuthoringBundle`                                                                                                                                                                                                                                                                                 | Deployed separately because agents depend on the Agentforce service being reachable |
| `package.xml`                       | same shape as core | Generic full manifest (ignored by `.forceignore` for source tracking)                                                                                                                                                                                                                                                               | Manual retrieval                                                                    |
| `member-classification-package.xml` | 3 members          | `Member__c.Member_Type__c` field + validation rules                                                                                                                                                                                                                                                                                 | One-off rollout of member classification                                            |

Validate before deploying: `./scripts/validate-deployment-package.ps1`.

When you add a new metadata type folder, add it to `core-package.xml` (wildcards or explicit members) or it will not ship in the release.
