# UI shell & org settings

Folders covered: `applications/`, `tabs/`, `flexipages/`, `networks/`, `sites/`, `staticresources/`, `settings/`, `profiles/`, `roles/`, `groups/`.

| Metadata                                                                     | What it is                                                                                                                                                                                                       |
| ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `applications/Library_Management.app`                                        | Standard-nav Lightning app "Library Management". Tabs: Book, Author, Book Category, Book Copy, Member, Membership Plan, Borrow Record, Reservation, Fine, Library Registration, **Library Librarian Workspace**. |
| `tabs/*.tab`                                                                 | 11 tabs — 10 object tabs + `Library_Librarian_Workspace` (the LWC `libraryLibrarianWorkspace`).                                                                                                                  |
| `flexipages/Library_Registration_Record_Page`                                | Record page for `Library_Registration__c` embedding `libraryRegistrationReview`.                                                                                                                                 |
| `networks/Library.network`                                                   | Experience Cloud network for the member site.                                                                                                                                                                    |
| `sites/Library.site`                                                         | Salesforce Site wrapper (`urlPathPrefix` `libraryvforcesite`, guest user `Library`).                                                                                                                             |
| `staticresources/LibraryAuthHero`                                            | PNG hero image for login/registration screens.                                                                                                                                                                   |
| `settings/Apex.settings`, `EmailAdministration.settings`, `Sharing.settings` | Org-level toggles deployed with the app.                                                                                                                                                                         |
| `profiles/Library Profile`                                                   | Profile for provisioned portal users.                                                                                                                                                                            |
| `roles/Library_Operations`                                                   | Role used by librarian users.                                                                                                                                                                                    |
| `groups/Library_Librarians`                                                  | Public group that receives sharing-rule access.                                                                                                                                                                  |

Open the app: App Launcher → _Library Management_ → _Library Librarian Workspace_ tab.
