# `scripts/apex/` — anonymous Apex

Run with `sf apex run --file scripts/apex/<name>.apex --target-org library-org`.

| Script                                                                           | Purpose                                                                                                                                                                                                              | Idempotent?    |
| -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------- |
| `add-10-dummy-members.apex`                                                      | Adds a coherent demo cohort of 10 members; exits without inserting if it already ran.                                                                                                                                | Yes            |
| `add-20-auth-uat-members.apex`                                                   | Creates `uat-member-01..20@example.com` on the Basic/Standard/Premium plans (needs those 3 active plans); skips if they already exist.                                                                               | Yes            |
| `prepare-5-auth-uat-members.apex`                                                | Prepares 5 UAT members with login state. **Set a one-time password only in the execution window; never commit it.**                                                                                                  | Yes            |
| `verify-uat-auth-state.apex`                                                     | Attempts a login/logout for each `uat-member-%@example.com` member and prints status. **Warning: the script contains a hard-coded UAT password** — treat it as test-only and remove/rotate it before any shared use. | Read-only      |
| `classify-member-types.apex`                                                     | One-time classification of `Member__c.Member_Type__c` (Production/Demo/Legacy); touches only that field.                                                                                                             | Yes            |
| `diagnose-member-catalog.apex`                                                   | Runs `LibraryMemberController.searchCatalog` as one specific org User (hard-coded User Id) and prints count/first title/error. Edit the Id for your org.                                                             | Read-only      |
| `resequence-all-reservation-queues.apex`                                         | Repairs `Queue_Position__c` after the switch to pending-only numbering.                                                                                                                                              | Yes            |
| `schedule_notification_retry.apex`                                               | Schedules `LibraryNotificationRetryScheduler` hourly if the named job is absent.                                                                                                                                     | Yes            |
| `unschedule-notification-scheduler.apex` / `restore-notification-scheduler.apex` | Pair used by `deploy-library.ps1` around deployments.                                                                                                                                                                | Yes            |
| `verify-email-delivery.apex`                                                     | Reserves e-mail capacity and sends a single test e-mail to the running user to confirm the org can send mail.                                                                                                        | Sends 1 e-mail |
| `validate-library-schema.apex`                                                   | Runs `LibrarySchemaValidation.validate()` and prints findings.                                                                                                                                                       | Read-only      |

Related: [`../seed/`](../seed/README.md) for bulk demo data.
