# `docs/testing/`

| File                       | Use                                                             |
| -------------------------- | --------------------------------------------------------------- |
| `TESTING_CHECKLIST.md`     | Quick regression checklist before a release                     |
| `UAT_TEST_PLAN.md`         | Formal UAT scenarios and expected results                       |

| `WEBSITE_TESTING_TOOLS.md` | Tools for browser/accessibility/performance testing of the site |
